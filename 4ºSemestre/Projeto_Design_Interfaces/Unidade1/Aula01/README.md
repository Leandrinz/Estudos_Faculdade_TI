# Aula 11/08/2026 - Apresentação da Disciplina
A disciplina foca na experiência/interação do usuário

### Usável
O design tem que ser fácil de usar

### Equitativo
Atender a diferentes públicos (pessoas com deficiências por exemplo)

### Agradável
O usuário precisa se sentir bem e cria uma conexão boa

### Útil
Resolve um problema

## Framework Google Sprint
É o framework que será usado na disciplina

## Entrega final
Jogo, artigo (10 a 15 páginas) e Registro de Software (pontos adicionais)
